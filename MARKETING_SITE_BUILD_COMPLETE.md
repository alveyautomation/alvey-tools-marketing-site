  prop, pricing line, primary CTA (placeholder URL), optional secondary CTA
  (placeholder Loom URL).
- **Problem statement** — what hurts and why this exists.

  `LANDING_PAGE.md` / `BUILD_COMPLETE.md`.
- **Who it's for** — qualifying / disqualifying criteria.
- **FAQ** — 6-7 questions per product, sourced from each product's source docs.
- **Final CTA** — repeat primary CTA + "Email a question" secondary CTA.

The placeholder coming-soon page (`qbo-mcp`) gets a "Coming soon" badge in the
hero, and the index card shows a "Soon" pill.

## Visual style

- **Theme:** dark, ink-color palette (`--color-ink-950 #0a0e1a` body) with
  **warm gold/orange accents** (`--color-amber-400 #fbbf24`,
  `--color-orange-400 #fb923c`, gradient `gradient-amber`). Matches Alvey
  Automation's existing `alvey-sites` aesthetic.
- **Typography:** Inter (body) + Playfair Display (headings, `font-display`)
  + JetBrains Mono (code spans). Loaded once from Google Fonts in
  `Default.astro`.
- **Mobile-responsive:** every page uses Tailwind's responsive breakpoints
  (`sm:`, `lg:`). Verified renders correctly down to ~360px width.
- **Zero JavaScript:** every landing page is pure static HTML + CSS. No
  client-side hydration, no framework runtime.
- **Accessibility:** semantic HTML5 (`<header>`, `<main>`, `<footer>`,
  `<article>`, `<section>`, `<dl>` for FAQs), `aria-label` on the logo and
  primary nav, `aria-hidden` on decorative SVGs, proper heading hierarchy
  (single `<h1>` per page).

## Accessibility quick check

- Single `<h1>` per page (the hero headline).
- `<h2>` for section headings, `<h3>` for sub-sections in product pages.
- All interactive elements are real `<a>` tags with `href`s — keyboard
  navigation works without JS.
- The decorative gradient SVG icons in buttons and cards have
  `aria-hidden="true"`.
- The header logo has `aria-label="Alvey Tools home"`; primary nav has
  `aria-label="Primary"`.
- Color contrast ratios spot-checked:
  - Ink-100 (#eef0f6) on ink-950 (#0a0e1a) = ~17:1 ✅
  - Ink-300 (#b9c0d6) on ink-950 = ~12:1 ✅
  - Amber-400 (#fbbf24) on ink-950 = ~12:1 ✅
  - All exceed WCAG AAA (7:1) for body text.
- No images shipped (logo is inline SVG via favicon URI). When Brett adds
  product screenshots later, ensure each carries a meaningful `alt`
